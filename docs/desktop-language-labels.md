# SOCI-AI 全库标签与提示

当前 300 条原创风险样例全部进入同一匹配与提示流程，每类 25 条。以下主题与机制标签由样例类别生成，不是只为某一句设置的触发器，也不是经过验证的心理或意图标签。

| 样例类别 | 显示的主题标签 | 机制标签 |
| --- | --- | --- |
| gender_ability | 性别能力偏见 | 能力预设 |
| gender_roles | 性别角色限定 | 角色限制 |
| age_bias | 年龄偏见 | 代际概括 |
| region_accent | 地域口音偏见 | 地域归因 |
| education_bias | 学历偏见 | 资格预设 |
| appearance_bias | 外貌偏见 | 外貌归因 |
| socioeconomic_bias | 经济背景偏见 | 家庭背景归因 |
| disability_bias | 健康残障偏见 | 能力泛化 |
| family_status | 婚育身份偏见 | 照护身份预设 |
| identity_othering | 身份归属排斥 | 归属限制 |
| ability_dismissal | 能力贬低 | 参与资格否定 |
| emotional_invalidation | 感受否定 | 体验轻视 |

涉及跑腿、分工、岗位等表达时，增加“任务分配”标签；合计 25 种标签。风险卡使用“疑似”措辞，展示实际识别原句、对应改写；悬停可查看库中原有解释和完整改写。60 条对照及明确否定/引用语境不作为偏见标签提示。

例如“学历低一点的人更适合跑腿”显示“学历偏见 / 资格预设 / 任务分配”，建议“按经验、能力和本人意愿分工”。“学历低点的人更适合跑腿”通过统一口语缩略匹配。若误听成“跑退”，仅显示待核对提示，不增加语义分数。

普通建议最少保留 8 秒，确认语言提醒保留 10 秒，新语言线索优先。字幕仍可能误听，全库规则测试不代表语音识别准确率。条目来源、原始权重、解释与完整改写仍在同目录 SQLite / JSON；原始数据和许可说明不变。
