# SOCI-AI 原生桌面版使用说明

## 打开与复制

新版双击 `SOCI-AI.exe`。只需发送这一个文件，不需要项目源码、网址、浏览器、Python 或安装依赖。首次启动会解压内置依赖到临时目录，稍慢是正常的。

旧版 `SOCI-AI-Desktop.exe` 仍需完整文件夹，不能与新单文件版混淆。新版面向现代 Windows 10/11 x64；不同电脑的摄像头和麦克风驱动仍需实测。程序未做数字签名，Windows 可能显示来源提示，请核对文件来源。单文件封装不等于代码无法被逆向提取。

窗口启动尺寸根据屏幕可用区域和 Windows 缩放自动适配。实时自检采用一屏布局，摄像头、两项面部指标、生命树、分数与字幕始终在同一屏内；反馈框高度固定，不会因语言提醒出现而挤动其他区域。较小窗口会压缩留白与图形尺寸。回顾与系统介绍保留纵向阅读。页面有“实时自检”“会话回顾”“系统介绍”三项。

## 首次检测

1. 关闭仍在使用摄像头的旧网页和会议软件。此程序不会关闭其他应用。
2. 保持停止状态，点击右上方“设置”选择麦克风；默认摄像头索引为 0。如果打不开，依次尝试索引 1、2。这些是候选索引，不是已验证设备列表。麦克风的原始硬件名称可悬停查看。
3. 点击“开始检测”。图像采集与本地流式语音模型分别启动，加载状态单独显示。
4. 对准自己，保持自然表情约 1 秒；程序会自动记录。如启动时就在皱眉，先放松，在“设置”中点击“重新记录自然表情”。
5. 以自然语速说普通话，观察输入电平、临时转录和停顿后的确认文字。初次加载比后续解码慢，界面不会等待它才更新视频。

## 如何观察变化

先自然交流，再短暂皱眉或撇嘴，观察摄像头下方的两个 0～100 动作强度读数：眉部紧张、嘴角下压。它们是相对本人中性基线的变化，不是情绪概率。相应动作持续约 250 毫秒后形成较强视觉线索。正常说话中的抿唇、噘嘴不参与负面评分，也不生成相关提醒。微笑仍在内部用于正向建议与枝叶反馈，不再显示单独指标；它不计为负面动作，也不会抵消语言风险。SBI 越高表示表达压力/风险线索越强，右侧友好度是 100−SBI，并非另一套独立测量。

表情基线使用前 8 个有效观测的中位数和 MAD 噪声门限。请在开始时保持自然表情约 1 秒；开始时已经皱眉、换人、显著改变角度或光线后，请重新校准。更高灵敏度不等于经过验证的更高准确率。

“设置”中的“重新记录自然表情”让程序重新记住你放松时的眉嘴状态，后续动作与此比较，减少个人眉型、嘴型差异的影响。每次开始都会自动记录，通常无需点击。只有开始时表情不自然，或换人、光线明显变化时，才需要放松后重设；记录期间按钮会暂时不可点击。

当 SBI 达到 60（友好度降到 40）时，圆环与生命树一起进入红色提示：树叶、枝干变红，出现红色光晕和“高风险 · 建议停顿”。指标下降后会平滑恢复。树的色彩与动画只是反馈方式，不会改动分数。

语言测试可使用以下几句（用于识别偏见的对照示例，不代表赞同）：

- “女生就是学不好工科吧。”
- “这你都不会？”
- “别这么敏感。”

先确认字幕确实识别出你的原话，再观察语义条与建议。否定对照可说“不要说女生学不好工科”或“我反对这种说法”。原型会尝试区分否定和引用，但复杂反讽、隐含语境及语音误识别仍可能漏报或误报。

主界面顶部的反馈卡显示对应标签、实际识别原句和一句简短改写。标签覆盖全部 300 条风险样例，包含 12 类主题和 12 类机制，并在相关语句中增加“任务分配”标签，不只针对某一个示例。标签详情可将鼠标放在反馈卡上查看。

顶部按当前信号分别提示：眉部紧张时“舒展眉头”，嘴角下压时“放松嘴角”，两者同时出现时同时提醒；实际音量压力升高时建议降低音量。回到平稳信号时，原表情/语气建议可保留 8 秒方便阅读；出现不同的明确动作会更新提示。确认文字的语言提醒从该次识别起保留 10 秒，新语言线索优先显示。临时文字显示黄色提醒，确认命中显示红色提醒，具体状态可悬停反馈框查看。过长的文字以省略号显示，悬停对应文字可查看完整原句、标签或建议。保留的是阅读卡片，SBI 仍根据新鲜信号计算、自然回落；刚才的语言提醒不代表当前仍在发言。

右侧友好度下方的“本场重点”独立汇总本场截至目前的实际观测，约每 10 秒重新评估，最多显示三条简短加粗建议，采用金色、浅蓝和薄荷绿，不使用红色。反复出现的眉部紧张、嘴角下压或较高音量压力，会分别提示“舒展眉头”“放松嘴角”“降低音量”；确认文字中的语言提醒按主要类别给出改进方向。短暂单次动作不会自动成为整场重点。悬停可查看观测比例或确认文字中的类别；没有有效输入时仅显示正在积累信号。极小工作区优先显示一条，其余建议可悬停查看。结束后保留最终重点，开始下一场时清空；保存、历史和导出仍按原流程使用。

“句间留出停顿”属于一般交流建议，不表示已检测到语速过快；沉默或缺少输入不会生成提高音量的提醒。当前模块没有可靠的语速或音高测量，不将音量升高写成音调过高。

全库统一支持“一点→点”“一些→些”的口语缩略。足够长的语句与样例只有一个非关键字符不同，可显示“近似转写，请核对字幕”；此类提示不计入 SBI，也不会把字幕改成库里的句子。否定词和主要身份/评价词不进行近似修正。原模型并没有提供经过校准的识别置信度，本界面不伪造百分比。更大改写、多字误听和复杂上下文仍需现场测试。

数字按照真实输入刷新，不会为了显得实时而随机跳动。眨眼、沉默、正常说话不应自动判为冒犯；稳定输入允许分数稳定。没有新鲜数据时显示“—”而不是保持旧分数。生命树由指标驱动变色与开花，不替代模型结果。

性能读数收进“设置”按钮的悬停提示。音频队列表示等待解码的积压；语音识别毫秒读数表示当前采集块到处理返回的年龄，包含采样与解码，不等同于从开始说话到第一段文字出现的总延迟。

## 结束与报告

点击“结束会话”释放设备，并在“会话回顾”查看时长、平均/峰值 SBI 与单条 SBI 曲线。曲线加粗、采用绿黄红渐变，60 分以上区段为红色；横轴是会话时间，纵轴是 SBI。缺失信号保留断点，鼠标移到图上可查看样本及当时的简短线索标签，例如“疑似学历偏见”“眉部紧张增强”“声音压力升高”，不显示整句发言。标签随当时实际信号记录，不复制顶部保留阅读的提醒；仅剩评分平滑余波时标注“回落中”。旧报告没有逐点标签时显示“未记录该点的具体线索”，不推测原因。人脸预览仅绘制跟随面部移动的轮廓，不叠加文字。下方是整场建议及最多三个重要时刻：重复语言样例合并，同一面部动作相隔不超过 15 秒的事件合并为一个展示区段，选取其中最强的实际观测。优先展示不同的语言与动作类型，余下名额才显示同一种动作的其他独立区段。区段不意味着动作在两次观测之间持续存在。确认转录默认折叠；完整原始事件与分数仍可导出，未删改。只有确认文字进入最终转录记录。

原“信号证据”页已合并到回顾，不再在结束后显示空白实时状态。“系统介绍”解释基线、语义样例检索、融合公式、时间平滑和边界。

## 中文社交语言样例库

新版内置 SQLite 数据库、JSON 和来源说明；开发工程的 `resources/language` 可供阅读。包含 300 条原创风险示例及 60 条友好/否定/引用对照，按类别、语境、解释和建议改写整理。参考 COLD、SWSR、CHBias 等公开研究的分类；条目是原创合成样例，不是从这些数据集中采集的真实会议发言，也不是已验证的训练集。

程序实际加载同一份样例库，结合轻量匹配和上下文规则产生语义线索，并与表情、声音线索融合。所有媒体处理与匹配在本地进行，不需要在线检索。便于查看的 `语料库` 副本不会覆盖内置数据库；如需扩展，请修改源码中的 JSON 并运行 `tools/build_language_database.py` 后重新打包。

## 本机会话历史

结束检测后自动转到“会话回顾”。点击“保存到历史”才将本次完整报告保存到本机；未选择保存前只保留在窗口内。关闭或开始下一场时会提醒选择保存、不保存或返回。突然断电、崩溃时尚未选择保存的报告无法恢复。

重新打开程序后，在“会话回顾”的“本机会话历史”下拉列表按日期选择以前的会话，直接重现 SBI 渐变曲线、逐点异常原因、整场总结、建议与确认转录，无需导入文件。记录按日期倒序展示，包含时长、平均/峰值 SBI 和完成状态；“更多记录”可以查看更早的记录。历史页与当前检测分离，查看旧记录时不会被当前实时信号覆盖。

整场总结优先概括反复或持续的眉部/嘴角动作、实际确认字幕中的偏见类别、音量压力变化，再给出针对性的改进建议。短暂变化与整场趋势分开表述；没有有效信号时明确说明。当前声音模块测量音量压力，不可靠测量说话语速或音高，不把大音量写成语速过快、音调过高，也不推断情绪或意图。

历史数据库固定保存在当前 Windows 账户的 `%LOCALAPPDATA%/SOCI-AI-Desktop/history.sqlite3`，日志在同目录的 `logs`，默认报告目录为 `exports`。移动或替换 EXE 不改变这一路径；不同电脑、不同 Windows 账户的记录互不相通。没有云同步、账户识别或数据库加密，同一账户下的使用记录属于同一个列表。

只保存分数、时间、逐点线索、确认转录、事件和建议，不保存原始视频、摄像头照片、音频或临时字幕。意外退出后，上次已落盘的记录标为“异常结束”，不伪造尚未保存的数据。旧版本没有落盘的历史无法恢复。

选中已结束或异常结束的会话，点击“删除本条”，核对确认框后删除该条；不影响其他会话，当前进行中的记录不能删除。此操作不可撤销，也不会删除此前另行导出的报告。“导出会话报告”可选择可直接阅读的 HTML（包含渐变曲线、原因、建议和确认转写）或 JSON 结构化数据。导出按钮导出当前选中的报告，而不是始终导出最新会话；导出与保存到历史是两个独立操作。

写入失败时会显示真实错误并允许重试。关闭时有未保存数据，会提示重试、保留窗口或放弃未保存内容；不会静默丢失记录。关闭窗口会等待本程序的工作线程安全结束，不会结束其他程序。

如果连续几次会话保存失败，下拉列表会逐条标明“未保存 · 可导出”；选中任意一条即可手动导出，不只限于最后一次。此类快照仍在内存中，不能当作已经落盘的历史；请重试保存或导出后再退出，不能删除尚未保存的快照来掩盖保存错误。

模型自检 `--self-test-models`、窗口自检 `--smoke-test` 和历史自检 `--self-test-history` 都不打开摄像头或麦克风。诊断命令必须先把 `SOCI_AI_TEST_DATA_DIR` 设为独立测试目录的绝对路径，测试结果只写入那里；正常启动不使用此变量。

## 原型边界

采用 MediaPipe 人脸动作系数、sherpa-onnx 中文流式语音识别与可解释语义规则。SBI 为尚未进行准确率验证的原型评分，表情/声音并不等同于恶意或心理状态，不用于招聘、纪律认定或医学诊断。包内自检及文件录音延迟不等同于现场硬件测试。

“系统介绍”中可以打开本说明及第三方软件与模型声明。模型并非本项目自行训练；公开或商业发布前仍需核对 Qt 等软件及模型权重的许可义务，单文件构建成功不等于已完成全部授权审查。
