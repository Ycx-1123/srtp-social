# SOCI-AI 原生版：指标与实现说明

本文描述当前代码，不代表经过验证的心理量表或识别准确率。所有阈值与权重都是原型工程参数；后续需要独立真实语境标注、跨人群评估和误报分析。眨眼、皱眉、微笑以及较大的音量均不能单独确定冒犯、人格或真实意图。

## 1. 面部动作：个体基线与噪声归一化

来源：MediaPipe Face Landmarker 的真实 blendshape 系数。眉部取 browDownLeft/Right，嘴角下压取 mouthFrownLeft/Right，微笑取 mouthSmileLeft/Right。mouthPressLeft/Right、mouthPucker 仅保留为旧格式诊断值，不显示、不参与负面评分；正常发音也会改变这些系数。

每个系数独立采集 8 帧自然表情。令其中位数为 m，MAD = median(|xᵢ−m|)，则：

```
g = max(0.006, 3 × 1.4826 × MAD)
f(x) = clip((max(0, x−m−g) / max(h, 6g))^0.75, 0, 1)
h = 0.18（眉部、嘴角下压），0.16（唇部），0.30（微笑）
```

同组取已校准有效系数的最大值，界面动作强度为 100f。基线不会持续跟随表情学习，以免把持续皱眉吸收为“正常”；更换人、角度或光照后可手动重新校准。强度只是相对基线变化，不是某种情绪的概率。

令 q=max(眉部、嘴角下压)。当 q≥0.18 且连续至少 250 ms 时产生持续线索。最近最多六个 q 的总体标准差为 σ：

```
c = 0.55 + 0.45 × clip(1−σ/0.45, 0, 1)
u = q × c（满足持续条件），否则为 0
V = max(u, 0.25q)
```

c 表示短时间稳定性权重，不是分类置信概率。微笑单独记录，用于提示与花苞反馈，不进入 V，也不会抵消不当措辞。缺失表情系数、无有效人脸或基线未就绪时，视觉不参与评分。关键点用于检测框和坐标有效性检查，没有用未经姿态校正的二维距离制造动作分数。

## 2. 声音：有限辅助线索

来源：本机麦克风的实际采样。在最新声音电平中，以滑窗中位 RMS 形成参考基线 b（下限 0.015）：

```
A = clip((RMS−max(0.09, 2.5b))/0.16, 0, 1)
```

它描述较高的声音电平，不等于生气、恶意或打断。当前实现没有说话人分离，因此不能声称判断了具体谁在打断谁。

## 3. 语言：场景样例库与上下文规则

本地中文流式 ASR 产生临时及确认文字。运行时加载 SQLite 场景库（300 条原创风险样例与 60 条对照；来源字段和人工设定权重均可查看），进行规范化样例匹配、有限模式匹配与否定/引用上下文过滤。它不是已训练完成的微冒犯分类模型。

命中项返回类别、解释、权重 w 与建议改写。未确认 ASR 片段采用 0.8w，确认文字采用 w。距最新对应文字的时间为 a 秒：

```
S = w × k × exp(−max(0, a−2)/4)   （0≤a<12）
k = 0.8（临时片段）或 1.0（确认文字）
```

12 秒之后不再使用该语义线索。解码积压重置时丢弃未确认的旧语义；不把几分钟前积压的音频误当成当前发言。命中不是语境判决，未命中也不表示所有说法都无偏差。规则词库的自测通过率不可当作真实环境准确率。

匹配结果统一返回中文主题标签、机制标签、命中原句与改写建议，覆盖全部 300 条风险样例。精确样例与限定变体优先；未命中时，再全库比较“一点/点”“一些/些”的安全口语缩略。对于长度至少 10 字、当前句子最多 128 字的一字符近似替换，仅提示人工核对；保护否定、身份、极性相关字，不进行插入/删除近似匹配。这种近似提示的语义分数为 0，不用于提高 SBI，不是模型置信度。

反馈卡与评分时序独立：普通建议最少停留 8 秒；确认语言提醒保留 10 秒，待确认片段仅在最近 2 秒有效且允许撤回。新语言线索优先显示。原始识别字幕不被匹配文本替代。当前分数仍使用上面的新鲜度和衰减公式，不能把阅读卡片停留误解为风险分数冻结。

## 4. 融合、时序与缺失信号

所有输入归一化至 0～1。视觉结果新鲜度 <0.6 s、声音采集 <0.8 s、语言 <12 s 才可用。目标分数和时序平滑如下：

```
T = clip(max(0.65V, 0.90S) + 0.12min(V,S) + 0.10A, 0, 1)
rₜ = rₜ₋₁ + (T−rₜ₋₁) × (1−exp(−Δt/τ))
τ = 0.18 s（目标上升）或 1.40 s（目标回落）
Δt = 本次与上次更新之差，上限 0.4 s
SBI = 100rₜ
友好度 = 100−SBI
```

友好度是反向刻度，不是独立评估模型。没有任何新鲜有效输入时显示“—”，不维持上一帧高分，也不输出虚构的默认友好分。稳定输入允许分数稳定；程序不通过随机数、录制剧本或计时器改变检测分数。

## 5. 回顾与生命树

界面约每 100 ms 拉取最新分析，摄像头预览独立约每 33 ms 刷新；模型处理的实际帧率由设备和负载决定，这些周期不代表端到端识别延迟保证。曲线约每 0.5 s 保留一个实际分数样本，平均值以所有有效界面更新样本计算，峰值覆盖抽样间的短暂变化；缺失值不参与平均，也不连成连续测量。

会后建议根据真实确认文字、动作峰值及可用观测时间生成。时间覆盖是受新鲜度门限限制的离散观测近似，不是帧级人工标注时长。展示最多三个关键时刻，优先不同的确认语言事件与不同面部动作类型；重复语言文本合并，同一面部动作相邻事件间隔不超过 15 秒时合并为展示区段，取其中最强实际观测。仅在名额有剩余时补充同类动作的其他独立区段。区段范围不证明其间连续发生该动作。原始确认转写与全部事件仍可导出核对。

回顾只绘制 SBI，不重复绘制互补的友好度。4.5 像素曲线按纵向数值使用绿黄红渐变，60 分及以上进入红色；加宽的低透明度描边仅用于视觉强调。曲线通过实际样本，在相邻点之间以水平切线的三次贝塞尔段连接，控制点位于两个实测值之间，不产生超出相邻分数的峰值；悬停仍读取实测样本，缺失值保持断开。它是展示插值，不是额外采样或模型预测。

每个曲线样本另存最多三个简短线索标签，不存整句发言作为悬停内容。解释记账把融合目标的最大主项归给获胜模态、协同项均分给视觉与语言、声音项独立记录；目标截断时按同一比例缩放。各标签贡献使用与 SBI 相同的平滑系数更新，旧标签逐步衰减，因此轻微新声音不会覆盖此前语言高分的来源。只展示贡献至少 1.5 分且至少占当前评分 10% 的标签，并标注正在回落的来源。它是规则评分来源的展示说明，不是验证过的因果解释，不反过来改变 SBI。旧记录缺少逐点标签时不推测原因。

生命树只显示已有分数：SBI<25 以舒展绿色为主；25≤SBI<60 为提醒；SBI≥60（友好度≤40）时，枝干与树叶转为醒目红色，配合红色光晕、边框与“高风险 · 建议停顿”提示，并逐渐下垂和落叶。圆环使用相同阈值。颜色快速过渡，枝叶形态缓慢变化；分数回落后恢复对应状态。花苞与微笑动作、低风险状态相关。自然摇摆和环境光点只是绘制动画，不会反馈生成 SBI。

## 6. 数据与适用边界

公开研究参考与许可信息见 `语料库/README.md`。本版库中的发言是为项目原创编写的合成场景，参考分类不等于复制公共数据，不得说成真实用户采样或已完成有效性验证。

本工具用于本人自检与沟通练习，不用于招聘筛选、纪律判断、医学诊断或推断他人的身份和人格。原始视频/音频不存盘；导出的会话文字由用户自行保管。系统介绍中的公式可用于如实介绍当前实现，尚未实现的说话人分离等功能应列为后续工作。
