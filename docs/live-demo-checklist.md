# SOCI-AI 实时答辩演示检查表

## 答辩前十分钟

- 连接电源，关闭会占用摄像头的腾讯会议、Teams、微信视频等程序。
- 在项目目录执行 `python -m pip install -r requirements-live.txt`。
- 双击 `start_showcase.bat`，确认能力检测中 YOLOv8、OpenCV 与权重均显示 `ready`。
- 确认浏览器地址为 `http://127.0.0.1:8001/`，默认页标题是“实时微冒犯自检”。
- 点击“开始实时自检”，允许摄像头与麦克风权限。

## 必须现场验证的真实链路

1. 自拍画面出现，脸部周围绘制绿色检测框和置信度。
2. 说话时麦克风波形真实变化，状态依次显示“正在监听、正在转写、正在分析”。
3. 正常表达时生命树保持绿色或青绿色、枝叶舒展。
4. 皱眉或提高音量时，视觉紧张度或语气压力发生变化；不要声称单一动作必然构成微冒犯。
5. 测试语句“女生不适合学工科”应出现在最新转录中，并提高语义偏差和综合 SBI。
6. 随后说“刚才的概括不准确，我们应该依据每个人的实际能力判断”，观察树进入恢复生长状态。
7. 点击“停止实时自检”，确认摄像头指示灯熄灭，并进入会后复盘查看结构化记录。

## 降级检查

- 拒绝摄像头权限：界面明确提示不可用，树保持银蓝中性，不出现模拟风险。
- 遮住摄像头或离开画面：人脸框消失并显示“等待清晰人脸”。
- FunASR/SenseVoice 缺失：显示“转写不可用”，视觉和基础声学仍可工作。
- YOLO 权重缺失：能力检测显示 `model_missing`，不得显示视觉模型正在运行。
- 无硬件应急：进入“备用回放”，页面必须持续显示 `SIMULATED`。

## 答辩口径

- 当前完成：单人自检、真实摄像头人脸框、真实麦克风波形、本地 YOLOv8、SenseVoice 接口与转写链路、语义规则、SBI 融合、动态生命树和会话结构化存储。
- 当前假设：近距离主讲者即摄像头前使用者。
- 声纹注册与多人分离：扩展接口已设计，当前未实现。
- 系统输出是行为辅助指标，不是人格、道德、医学或心理诊断。
- 原始帧和音频窗口仅在内存中处理，不写入 SQLite；数据库只保存特征、转录、分数和提示。
