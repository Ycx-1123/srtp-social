# 指标与证据口径

## 三类来源标签

| 标签 | 可以表达什么 | 不可以表达什么 |
|---|---|---|
| `MEASURED` | 当前仓库由测试、脚本或代码路径直接验证的事实 | 未经独立实验的模型效果 |
| `TARGET` | 端侧延迟、F1、FPS 等下一阶段工程目标 | “已经达到”“优于基线” |
| `SIMULATED` | 确定性场景生成的 SBI、置信度和干预效果 | 真实用户研究结果 |

答辩时建议使用“原型演示显示”“当前实现支持”“工程目标是”，避免把模拟值说成真实测量。这样既可完整展示体系，也能清楚回答数据从哪里来。

## 当前可实测事实

- 默认模式无网络请求、无重型 ML 导入。
- 三个场景可以确定性重放并生成会话报告。
- 四模态融合、可靠度门控、时间衰减、跨模态协同、干预冷却与匿名化有自动化测试。
- supplied dataset 的文件数、类别数和 SHA-256 重复由审计脚本直接计算。

## 数据集结论

原数据集训练和验证各 887 个文件。验证集 887 个文件均能在训练集中找到相同 SHA-256 内容，分布于 883 个唯一哈希组；同相对路径碰撞为 887。因此任何基于该划分得到的高验证准确率都不能被视为独立泛化证据。

建议后续流程：按内容哈希分组去重，再按主体或采集会话分组划分；保留不参与调参的测试集；同时报告宏平均 F1、各类召回、混淆矩阵和置信区间。

## SBI 的解释边界

SBI 是面向当前会话的融合能量刻度，不是心理量表。阈值用于展示策略分层，不代表个体“有偏见”或“有攻击性”。当可靠通道不足时，界面必须显示“证据不足”而非 0；0 容易被误解为已经确认安全。

## 演示截图规范

截图应保留右上角来源标签。模型卡中的延迟/F1 若为目标必须同时显示 `TARGET`。场景曲线、反事实策略和置信度必须显示 `SIMULATED`。数据集审计显示 `MEASURED`，并保留无效独立评估的警告。
