# 🚨 SOCI-AI: 多模态社交辅助预警雷达
**A-Team AI Lab | 基于本地边缘计算的隐私安全社交守护系统**

**SOCI-AI** 是一款致力于提升社交沟通质量、预防职场/日常沟通冷暴力的辅助预警工具。本系统采用纯本地离线架构，确保用户隐私数据“不出主板”。
当前版本通过实时捕捉并分析环境语音，构建了**“语义解析 + 情绪捕捉 + 物理声学指标”**的四维交叉诊断雷达，并在高压或偏见沟通场景下提供动态社交干预建议。

## ✨ 核心特性 (Core Features)

- **⚡ 毫秒级极速响应 (GPU 直连)**：彻底斩断磁盘 I/O，音频流通过 `float32` 张量直接馈入显存，实现真正的零延迟推理。
- **🎙️ 动态断句雷达 (Smart VAD)**：基于连续监听的智能休眠与唤醒机制，自然捕捉语句停顿，无需手动干预。
- **🎭 多模态特征提取**：底层接入 SenseVoice 大模型，不仅识别文字，更能精准捕获 `愤怒`、`叹气`、`冷笑` 等非语言事件及环境噪音。
- **🚦 社交风险红绿灯**：
  - **声学维度**：实时计算物理语速 (CPS) 与音量峰值防爆音监测。
  - **语义维度**：自定义社交偏差词库，精准定位刻板印象与攻击性词汇。
  - **综合诊断**：前端根据风险等级自动生成 HTML 警报徽章与深度沟通建议。
- **🖥️ 商业级 UI 指挥中心**：采用 Gradio 构建的现代暗黑科技风 (Monochrome) 仪表盘，支持生命周期安全切断（优雅关机）。

## ⚙️ 环境依赖与安装 (Setup)

本项目依赖带 CUDA 加速的 GPU 环境（已在 RTX 4050 显卡下验证通过）。

### 1. 创建并激活虚拟环境
```bash
conda create -n soci_env python=3.10.19 -y
conda activate soci_env


### 2. 安装核心依赖
请先确保已安装与你电脑 CUDA 版本匹配的 PyTorch。然后安装本项目专用包：
pip install funasr numpy gradio pyaudio



🚀 启动指南 (Usage)
在项目根目录下，运行前端指挥中心：
Bash
python speech/soci_app_pro.py
终端启动成功后，会自动在浏览器中打开 http://127.0.0.1:7860。
点击页面上的 “▶️ 启动全天候雷达” 按钮，系统将自动开始环境监听与诊断。
